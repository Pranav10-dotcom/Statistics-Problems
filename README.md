# Statistics Python Coding Problems

This repository contains Python implementations of statistical concepts covered in the Statistics course.

## Unit 1 – Introduction to Statistics

The Unit 1 notebook covers:

- Introduction to Statistics
- Descriptive Statistics
- Inferential Statistics
- Sampling Techniques
- Correlation
- Regression

## Concepts Practiced

### 1. Descriptive Statistics
Worked with student score data to calculate and understand:

- Mean
- Median
- Mode
- Standard Deviation
- Variance
- Minimum and Maximum values
- Quartiles

### 2. Inferential Statistics
Introduction to making inferences about a population using sample data.

### 3. Sampling Techniques
Implemented Simple Random Sampling using Python.

### 4. Correlation
Calculated the correlation between Math and Science scores and visualized the relationship using a scatter plot.

### 5. Regression
Implemented Linear Regression to study the relationship between Math and Science scores and predict a Science score based on a Math score.

## Technologies Used

- Python
- Pandas

- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab
